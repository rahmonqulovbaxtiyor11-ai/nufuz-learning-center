# NUFUZ Global Launch

Create a polished, realistic, highly creative bilingual (Uzbek and English) marketing website for NUFUZ Learning Center. Use the supplied Instagram profile as brand/reference: NUFUZ, established 2020, IELTS | CEFR | SAT | General English, 3000+ learners, 7.0+ IELTS, professional mock exams, location Gijduvon. Make Uzbek the default language with a clear Uzbek/English switcher that translates all visible content. Design a premium modern learning-center landing page with a beautiful transparent/blurred sticky top bar on scroll. Include hero, programs focused primarily on IELTS and Multilevel/CEFR, credible stats, an engaging student-results showcase inspired by the third reference image but distinct and tailored to IELTS bands and Multilevel levels, and a teachers section with 4–5 teacher feature cards inspired by the second reference: portrait, personal achievement/results, bio, and student quote. Use realistic sample names/results but clearly structure content so it can be replaced. Include about, testimonials, FAQ, location/contact, and strong enrolment CTAs. Build the complete responsive site, use the attached images only as visual reference rather than copying their people/graphics, and generate appropriate original visual assets/placeholders where helpful.
